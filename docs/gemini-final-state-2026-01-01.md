# **Project State: Hybrid Hugo + GCS Portfolio**

## **1. Project Overview**

A serverless photography portfolio that combines static hosting speed with cloud storage flexibility.

* **Frontend:** Hugo (GitHub Pages) + Tailwind CSS + Alpine.js.  
* **Backend:** Google Cloud Storage (Assets & JSON Metadata).  
* **Logic:** Python `sync_engine.py` (runs in CI) scans GCS, extracts EXIF, generates thumbnails, and builds a JSON manifest.  
* **Commerce:** "Smart Buttons" for Lemon Squeezy (Direct Sales) and Agency Links (Licensing).

## **3. Google Cloud Storage Schema**

Bucket: `[GCS_BUCKET_NAME]`

* **Permissions:** `allUsers` = `Storage Object Viewer  `
* **Folder Hierarchy:**  
  * `/originals/[gallery-id]/`
    * `image_WM.jpg` (Watermarked display copy)  
    * `config.json` (Metadata, Stories, Product IDs)  
  * `/thumbnails/[gallery-id]/` (Auto-generated WebP)

## **4. GitHub Configuration**

* **Secrets Configured:**  
  * `GCS_BUCKET_NAME`  
  * `GCP_SERVICE_ACCOUNT`  
  * `GCP_WORKLOAD_IDENTITY_PROVIDER`  
  * `ACTIONS_STEP_DEBUG` (Enabled)
